HALLAZGOS
---------
LO QUE ESTÁ BIEN
- Cada registro nuevo copia del set el Cultivo, MCT, Generación, Programa, Trial, Tipo de operación,
  Field e Invernadero.
- Los registros con campos vacíos son antiguos, o de sets que no tenían ese dato cuando se registraron.

LO QUE HAY QUE CORREGIR
1) btnCalcMetasRef ("Recalcular metas") no lee todos los registros.
   - Hace una sola consulta a SharePoint, y SharePoint devuelve como máximo 2000 filas.
   - Si en 180 días hay más registros, las metas P75 se calculan con datos incompletos.
   - Además, agrupa a todas las personas sin código como si fueran una sola ("s/c").
   - btnCargarGlobal (Análisis global) tiene el mismo límite.
2) btnFinCosecha y btnFinCosecha_1 no tienen ninguna restricción: cualquier usuario puede marcarlos.
3) Los correos de peso no salen.
   - Revisa en las Fórmulas de App: rutaPesoCorreos, gloMailPesoTo, gloMailPesoCc y gloMailPesoDefault.
   - Tienen textos como "Tomate", "SPA" o "Todos PESO", que no son correos.
   - El registro sí se guarda, pero el envío del correo falla.
   - Reemplázalos por direcciones reales o por listas de distribución.

ANTES DE EMPEZAR
- En Configuración > General > Límite de filas de datos debe decir 2000.
- Exporta la lista REGISTRO_PERSONAL1 a Excel desde SharePoint, como respaldo.
- Si algún flujo de Power Automate se dispara "cuando se modifica un elemento" en REGISTRO_PERSONAL1,
  desactívalo mientras aplicas los cambios masivos.

ESTILOS DE BOTÓN
- Estilo A = Lima
- Estilo B = Contorno lima
- Estos estilos son los mismos del archivo de estilos que ya te envié.

====================================================================================================
2. PANEL "🛠 DATOS": COMPLETAR DATOS DEL SET Y CORREGIR CÓDIGOS (solo administrador)
====================================================================================================
El panel trabaja por pasos y nada se modifica hasta que presionas "Aplicar":
  1) Cargar los registros de un rango. Se leen día por día, así que no les afecta el límite de 2000.
  2) Analizar. Muestra cuántos registros cambiarían y cuáles. Todavía no se modifica nada.
  3) Aplicar. Guarda solo los cambios analizados.
  4) Recalcular metas, al terminar.

Reglas de seguridad para los códigos:
- Solo se cambia el código si el nombre aparece UNA sola vez en CATALOGO_PERSONAL1, o si todas sus
  apariciones tienen el mismo código.
- Si el nombre se repite con códigos distintos, o no existe en el catálogo, NO se toca y aparece
  en una lista para revisarlo a mano.
- El botón "Deshacer" revierte el último cambio de códigos mientras no cierres la app.

2.3 btnMantCargar · OnSelect
----------------------------------------------------------------------------------------------------
=Set(gMantDesde; Coalesce(dpMantDesde.SelectedDate; DateAdd(Today(); -30; TimeUnit.Days)));;
Set(gMantHasta; DateAdd(Coalesce(dpMantHasta.SelectedDate; Today()); 1; TimeUnit.Days));;
If(
    DateDiff(gMantDesde; gMantHasta; TimeUnit.Days) > 120;
    Notify("Usa rangos de máximo 120 días (por ejemplo, un trimestre a la vez)."; NotificationType.Warning);
    Clear(colMantReg);;
    Clear(colMantDS);;
    Clear(colMantSet);;
    Clear(colMantNombres);;
    Clear(colMantCod);;
    ForAll(
        Sequence(DateDiff(gMantDesde; gMantHasta; TimeUnit.Days); 0) As d;
        With(
            { _i: DateAdd(gMantDesde; d.Value; TimeUnit.Days) };
            Collect(
                colMantReg;
                ShowColumns(
                    Filter(REGISTRO_PERSONAL1; FechaInicio >= _i; FechaInicio < DateAdd(_i; 1; TimeUnit.Days));
                    ID; SetName; NombrePersona; CODIGO; DEPARTAMENTO; Cultivo; MTC; Generation; Program; TrialIntent; Field; Greenhouse; TypeOperation; FechaInicio
                )
            )
        )
    );;
    Notify("📥 " & CountRows(colMantReg) & " registros cargados. Todavía no se ha modificado nada."; NotificationType.Information)
)

2.4 btnMantAnalizarSet · OnSelect
----------------------------------------------------------------------------------------------------
=If(
    IsEmpty(colMantReg);
    Notify("Primero presiona 1️⃣ Cargar registros."; NotificationType.Warning);
    ClearCollect(
        colMantDS;
        ForAll(
            Filter(Distinct(colMantReg; Trim(SetName)); Not(IsBlank(Value))) As s;
            With(
                { _ds: LookUp(DATASUMMARY1; SetName = s.Value) };
                {
                    SetName:    s.Value;
                    Encontrado: Not(IsBlank(_ds.ID));
                    Crop:       _ds.Crop.Value;
                    Mct:        _ds.MCT.Value;
                    Gen:        _ds.Generation.Value;
                    Prog:       _ds.Program.Value;
                    Trial:      _ds.TrialIntent.Value;
                    TipoOp:     _ds.OperationType.Value;
                    Fld:        _ds.Field;
                    GH:         _ds.Greenhouse
                }
            )
        )
    );;
    ClearCollect(
        colMantSet;
        Filter(
            ForAll(
                colMantReg As r;
                With(
                    { dd: LookUp(colMantDS; SetName = Trim(r.SetName)); _w: chkMantSobrescribir.Value };
                    With(
                        {
                            _cul:  If(_w Or IsBlank(r.Cultivo);             Coalesce(dd.Crop;   r.Cultivo);             r.Cultivo);
                            _mct:  If(_w Or IsBlank(r.MTC);                 Coalesce(dd.Mct;    r.MTC);                 r.MTC);
                            _gen:  If(_w Or IsBlank(r.Generation);          Coalesce(dd.Gen;    r.Generation);          r.Generation);
                            _prog: If(_w Or IsBlank(r.Program);             Coalesce(dd.Prog;   r.Program);             r.Program);
                            _tri:  If(_w Or IsBlank(r.TrialIntent);         Coalesce(dd.Trial;  r.TrialIntent);         r.TrialIntent);
                            _op:   If(_w Or IsBlank(r.TypeOperation.Value); Coalesce(dd.TipoOp; r.TypeOperation.Value); r.TypeOperation.Value);
                            _fld:  If(_w Or IsBlank(r.Field);               Coalesce(dd.Fld;    r.Field);               r.Field);
                            _gh:   If(_w Or IsBlank(r.Greenhouse);          Coalesce(dd.GH;     r.Greenhouse);          r.Greenhouse)
                        };
                        {
                            ID:          r.ID;
                            SetName:     r.SetName;
                            Cultivo:     _cul;
                            MTC:         _mct;
                            Generation:  _gen;
                            Program:     _prog;
                            TrialIntent: _tri;
                            TipoOp:      _op;
                            Field:       _fld;
                            Greenhouse:  _gh;
                            Cambia:      dd.Encontrado And (
                                             ("" & _cul)  <> ("" & r.Cultivo)     Or ("" & _mct) <> ("" & r.MTC) Or
                                             ("" & _gen)  <> ("" & r.Generation)  Or ("" & _prog) <> ("" & r.Program) Or
                                             ("" & _tri)  <> ("" & r.TrialIntent) Or ("" & _op)  <> ("" & r.TypeOperation.Value) Or
                                             ("" & _fld)  <> ("" & r.Field)       Or ("" & _gh)  <> ("" & r.Greenhouse)
                                         )
                        }
                    )
                )
            );
            Cambia
        )
    );;
    Notify("🔍 Análisis listo: " & CountRows(colMantSet) & " registros por completar. No se ha modificado nada."; NotificationType.Information)
)

2.7 btnMantAnalizarCod · OnSelect
----------------------------------------------------------------------------------------------------
=If(
    IsEmpty(colMantReg);
    Notify("Primero presiona 1️⃣ Cargar registros."; NotificationType.Warning);
    ClearCollect(
        colMantCatKey;
        ForAll(
            ShowColumns(CATALOGO_PERSONAL1; CODIGO; Nombre; DEPARTAMENTO; Activo) As c;
            { Clave: Lower(Trim(c.Nombre)); Codigo: Upper(Trim(c.CODIGO)); Depto: c.DEPARTAMENTO; Activo: c.Activo }
        )
    );;
    ClearCollect(
        colMantNombres;
        ForAll(
            Filter(Distinct(colMantReg; Lower(Trim(NombrePersona))); Not(IsBlank(Value))) As n;
            With(
                { _c: Filter(colMantCatKey; Clave = n.Value) };
                {
                    Clave:    n.Value;
                    Estado:   If(IsEmpty(_c); "Sin coincidencia"; CountRows(Distinct(_c; Codigo)) = 1; "OK"; "Ambiguo");
                    Codigo:   If(CountRows(Distinct(_c; Codigo)) = 1; First(_c).Codigo; "");
                    Depto:    If(CountRows(Distinct(_c; Codigo)) = 1; First(_c).Depto; "");
                    Opciones: Concat(_c; Codigo & If(Activo = "SI"; ""; " (inactivo)"); ", ")
                }
            )
        )
    );;
    ClearCollect(
        colMantCod;
        Filter(
            ForAll(
                colMantReg As r;
                With(
                    { m: LookUp(colMantNombres; Clave = Lower(Trim(r.NombrePersona))) };
                    {
                        ID:           r.ID;
                        Persona:      r.NombrePersona;
                        CodigoOrig:   r.CODIGO;
                        CodigoActual: Upper(Trim("" & r.CODIGO));
                        CodigoNuevo:  m.Codigo;
                        DeptoActual:  r.DEPARTAMENTO;
                        DeptoNuevo:   If(IsBlank(r.DEPARTAMENTO); m.Depto; r.DEPARTAMENTO);
                        Ok:           m.Estado = "OK"
                    }
                )
            );
            Ok And (CodigoActual <> CodigoNuevo Or ("" & DeptoActual) <> ("" & DeptoNuevo))
        )
    );;
    Notify("🔍 " & CountRows(colMantCod) & " registros tienen un código distinto al del catálogo. Revisa la lista antes de aplicar."; NotificationType.Information)
)

NOTAS
- Si un nombre aparece varias veces en el catálogo con códigos distintos, no se elige ninguno, aunque
  una de esas personas esté inactiva.
  Motivo: los registros antiguos podrían ser de la persona inactiva. Esos casos quedan en la lista de
  la derecha para que los revises a mano.
- El departamento solo se completa si estaba vacío. Si ya tenía valor se conserva, porque es el que
  la persona tenía cuando trabajó.

1) Corrige los códigos duplicados en CATALOGO_PERSONAL1.

4) Completa los datos del set: presiona 2️⃣ Analizar, revisa el resumen y presiona Aplicar.
5) Corrige los códigos:
   a. Presiona Cargar otra vez.
   b. Presiona 3️⃣ Analizar códigos.
   c. Revisa las dos listas: la de cambios (código anterior → código nuevo) y la de nombres por revisar.
   d. Presiona Aplicar.
6) Repite los pasos 3 a 5 con el trimestre anterior, hasta cubrir todo el historial.
7) Al terminar todos los rangos, presiona 🔄 Recalcular metas una sola vez.
