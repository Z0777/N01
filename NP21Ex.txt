 1. SHAREPOINT
═══════════════════════════════════════════════════════════════════════════════
 1.1 CONFIG_PESO_CORREOS (lista NUEVA, en el sitio de la app)
   Title (= cultivo, exactamente como sale en DATASUMMARY1.Crop: Tomato,
   Tomato cherry, Pepper, Melon, Watermelon, Cucumber…) · Para (texto: correos
   separados por ";") · Copia (texto: correos separados por ";") · Activo
   (Sí/No, predeterminado Sí).
   Crea una fila con Title = DEFAULT: es el correo que se usa cuando el
   cultivo no tiene fila (antes era gloMailPesoDefault).
   Pasa aquí las filas que hoy están en la fórmula rutaPesoCorreos.
   Desde ahora, cambiar a quién le llega el correo de peso = editar esta lista
   (sin publicar la app).

 1.2 Carpeta "Personal" para TODAS las descargas (sitio Proyectos-usuarios)
   Documentos → Nuevo → Carpeta → Personal. Dentro:
     Personal/Plantilla   → sube aquí PlantillaVacia.xlsx (un libro de Excel
                            vacío con una sola hoja)
     Personal/Scripts     → aquí va ExportarExcelGenerico.osts (sección 10.1)
   Los Excel y PDF que se generen quedan directo en Personal.
   Permisos: Personal → ⋯ → Administrar acceso → los usuarios de la app con
   permiso de LECTURA (para abrir lo que descargan).

 1.3 ACCESOS_USUARIOS — ANTES de cambiar las fórmulas de la sección 2
   Revisa que exista TU fila: Title = tu correo en minúsculas, Rol =
   Administrador, Activo = Sí. Desde ahora el administrador sale SOLO de esta
   lista (la fórmula adminEmails se elimina). Si tu fila no está, pierdes el
   acceso de administrador al publicar.

 1.4 ROLES_PERMISOS / ACCESOS_USUARIOS — quién registra peso
   • Rol de peso: Permisos = rendimientos;rendimientos_peso
   • A otra persona con otro rol, sin cambiarle el rol: en su fila de
     ACCESOS_USUARIOS escribe en PermisosExtra:  rendimientos_peso
   • Para quitárselo: bórralo de PermisosExtra, o escribe rendimientos_peso
     en PermisosQuitar.
   Todo se hace desde la vista Accesos de la app o editando la lista; ya no
   hay correos de peso dentro de las fórmulas.

 Después: Power Apps → Datos → + Agregar datos → SharePoint →
 CONFIG_PESO_CORREOS.

 3. PERSONAL · ACTIVAR / DESACTIVAR VARIAS PERSONAS A LA VEZ
═══════════════════════════════════════════════════════════════════════════════
 Cómo funciona:
  • El botón ✔ Activo / ⛔ Inactivo de cada tarjeta ahora SELECCIONA (☑).
  • Al seleccionar la primera persona aparece abajo la barra de selección:
    cuántas van, "Seleccionar todos los visibles", "👁 Ver seleccionados"
    (filtra la galería para revisar), "✖ Limpiar" y "Cambiar estado (N) ›".
  • Puedes seguir buscando / filtrando y agregando más a la selección.
  • "Cambiar estado" abre el popup: el título dice cuántas personas son,
    eliges ⛔ Dar de baja o ✔ Reactivar, fecha y motivo, y se guarda a todas
    de una vez (catálogo + historial).
  • Si eliges Baja, solo se aplica a las seleccionadas que están activas (las
    inactivas se saltan) y al revés con Reactivar.

 4. PERSONAL · HORAS EXTRAS: HORAS REALES EN LOTE
═══════════════════════════════════════════════════════════════════════════════
 Cómo funciona:
  • El botón ⏱ de cada solicitud autorizada ahora SELECCIONA (☑⏱).
  • En la barra de Análisis aparecen: "☑ Autorizadas visibles", "👁 Ver
    seleccionadas", "✖" y "⏱ Horas reales (N) ›".

    seleccionadas, calcula las horas reales y ajusta el acumulado de cada
    persona según la diferencia.
  • Quien no tiene he_autorizar no puede guardar horas reales mayores a las
    autorizadas de alguna de las seleccionadas.

 10.1 OFFICE SCRIPT  "ExportarExcelGenerico"
 ────────────────────────────────────────────
   1. Abre Personal/Plantilla/PlantillaVacia.xlsx en Excel para la web.
   2. Automatizar → Nuevo script → borra todo y pega el código de abajo →
      cambia el nombre a ExportarExcelGenerico → Guardar script.
   3. Para dejarlo en SharePoint: en el editor ⋯ → "Guardar como" → elige
      el sitio Proyectos-usuarios → Documentos → Personal → Scripts.
      Si tu Excel no muestra esa opción: abre tu OneDrive → Mis archivos →
      Documentos → Scripts de Office → descarga ExportarExcelGenerico.osts
      → súbelo a Documentos/Personal/Scripts del sitio.

────────────────────────── CÓDIGO DEL SCRIPT (TypeScript) ──────────────────────────
interface Fila {
  [clave: string]: string | number | boolean | null;
}

function main(
  workbook: ExcelScript.Workbook,
  nombreHoja: string,
  columnas: string,
  datosJson: string
): number {
  // 1. Columnas ("A;B;C") y datos (JSON de Power Apps)
  const cols: string[] = (columnas || "")
    .split(";")
    .map((c) => c.trim())
    .filter((c) => c.length > 0);
  let datos: Fila[] = [];
  try {
    datos = JSON.parse(datosJson || "[]") as Fila[];
  } catch (e) {
    datos = [];
  }
  const nCol = cols.length;
  const nFil = datos.length;

  // 2. Una sola hoja, limpia, con el nombre pedido
  let titulo = (nombreHoja || "Datos").replace(/[\\\/\?\*\[\]:]/g, "").substring(0, 31);
  if (titulo.length === 0) {
    titulo = "Datos";
  }
  const hojas = workbook.getWorksheets();
  const hoja = hojas[0];
  for (let i = hojas.length - 1; i > 0; i--) {
    hojas[i].delete();
  }
  hoja.setName(titulo);
  hoja.getRange().clear(ExcelScript.ClearApplyTo.all);
  if (nCol === 0) {
    hoja.getRange("A1").setValue("Sin columnas para exportar");
    return 0;
  }

  // 3. Valores: vacío para null, Sí/No para verdadero/falso
  const filas: (string | number)[][] = [];
  for (let i = 0; i < nFil; i++) {
    const d = datos[i];
    const fila: (string | number)[] = [];
    for (let j = 0; j < nCol; j++) {
      const v = d[cols[j]];
      if (v === null || v === undefined) {
        fila.push("");
      } else if (typeof v === "boolean") {
        fila.push(v ? "Sí" : "No");
      } else if (typeof v === "number") {
        fila.push(v);
      } else {
        fila.push(String(v));
      }
    }
    filas.push(fila);
  }

  // 4. Formato por columna: número = General; lo demás = Texto (así Excel
  //    no cambia fechas dd/mm/yyyy ni códigos con ceros)
  for (let j = 0; j < nCol; j++) {
    let esNumero = nFil > 0;
    for (let i = 0; i < nFil; i++) {
      if (filas[i][j] !== "" && typeof filas[i][j] !== "number") {
        esNumero = false;
        break;
      }
    }
    if (nFil > 0) {
      hoja.getRangeByIndexes(1, j, nFil, 1).setNumberFormat(esNumero ? "General" : "@");
    }
  }

  // 5. Encabezado y datos (en bloques de 1000 filas)
  hoja.getRangeByIndexes(0, 0, 1, nCol).setValues([cols]);
  const bloque = 1000;
  for (let i = 0; i < nFil; i += bloque) {
    const parte = filas.slice(i, i + bloque);
    hoja.getRangeByIndexes(1 + i, 0, parte.length, nCol).setValues(parte);
  }

  // 6. Tabla con estilo y encabezado oscuro
  const totalFilas = Math.max(nFil, 1) + 1;
  const tabla = hoja.addTable(hoja.getRangeByIndexes(0, 0, totalFilas, nCol), true);
  tabla.setName("T_" + titulo.replace(/[^A-Za-z0-9_]/g, "_"));
  tabla.setPredefinedTableStyle("TableStyleMedium7");
  const enc = tabla.getHeaderRowRange();
  enc.getFormat().getFill().setColor("#0E2018");
  enc.getFormat().getFont().setColor("#FFFFFF");
  enc.getFormat().getFont().setBold(true);
  enc.getFormat().setWrapText(true);
  enc.getFormat().setVerticalAlignment(ExcelScript.VerticalAlignment.center);

  // 7. Ancho de columnas (máximo 260 pt con ajuste de texto) y encabezado fijo
  hoja.getRangeByIndexes(0, 0, totalFilas, nCol).getFormat().autofitColumns();
  for (let j = 0; j < nCol; j++) {
    const col = hoja.getRangeByIndexes(0, j, 1, 1).getEntireColumn();
    if (col.getFormat().getColumnWidth() > 260) {
      col.getFormat().setColumnWidth(260);
      hoja.getRangeByIndexes(1, j, totalFilas - 1, 1).getFormat().setWrapText(true);
    }
  }
  hoja.getFreezePanes().freezeRows(1);

  // 8. Página para el PDF: horizontal, carta, 1 página de ancho,
  //    encabezado repetido en cada hoja, título y número de página
  const pag = hoja.getPageLayout();
  pag.setOrientation(ExcelScript.PageOrientation.landscape);
  pag.setPaperSize(ExcelScript.PaperType.letter);
  pag.setCenterHorizontally(true);
  pag.setPrintMargins(ExcelScript.PrintMarginUnit.centimeters, {
    top: 1.5,
    bottom: 1.2,
    left: 0.8,
    right: 0.8,
    header: 0.5,
    footer: 0.5
  });
  pag.setZoom({
    horizontalFitToPages: 1,
    verticalFitToPages: Math.max(1, Math.ceil(totalFilas / 35))
  });
  pag.setPrintTitleRows("$1:$1");
  const hf = pag.getHeadersFooters().getDefaultForAllPages();
  hf.setCenterHeader("&B" + titulo);
  hf.setLeftFooter("&D &T");
  hf.setRightFooter("Página &P de &N");

  return nFil;
}

 12. LO QUE INTERPRETÉ (revísalo)
═══════════════════════════════════════════════════════════════════════════════
  • Activo/Inactivo en lote: la acción (baja o reingreso) se elige en el
    popup. Si la selección mezcla activos e inactivos, solo se aplica a los
    que cambian; los demás se saltan y se avisa cuántos.
  • Horas reales en lote: se aplica la MISMA hora real a todas las
    seleccionadas (es el caso de grupos que entraron y salieron juntos). Si
    alguna tuvo otro horario, quítala de la lista del popup y hazla aparte.
  • "Más de un día abierto" = abierto un día y cerrado otro día. Esos no
    entran en ningún análisis. El análisis del set ahora usa el mismo
    máximo de horas que el global (MaxHorasRegistro = 9 h; antes 10 h).
  • Los registros que quedaron En Proceso de días anteriores se quedan así
    en la base de datos: ya no aparecen en Finalizar, en las tarjetas ni en
    Procesos, y no cuentan en análisis.
  • Asistencia en garita: la lista de personal es de UN día (el "Desde").
    Los permisos sí muestran todo el rango. Solo cuenta permisos
    AUTORIZADOS. "Descanso" sale según la jornada (si no tiene, L-V).
  • En la copia del Detalle dejé CÓDIGO, NOMBRE, DEPARTAMENTO y ESTADO; las
    horas de ingreso y salida van dentro del ESTADO (no como columnas).
  • El administrador ahora sale solo de ACCESOS_USUARIOS (Rol =
    Administrador). Si alguien pierde el acceso, se corrige en la lista, no
    en la app.
  • PDF: se convierte dentro de SharePoint (sin OneDrive). El Excel
    intermedio se borra y queda solo el PDF.
